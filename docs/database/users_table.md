# 📋 users

> Пользователи, их учётные данные и роли.

## 🧾 Поля таблицы

| Поле | Тип | Обязательность поля | Значение по умолчанию | Описание |
|------|-----|------------------:|----------------------|----------|
| `id` | `bigint` | ✅ | `generated always as identity` | Идентификатор пользователя |
| `username` | `varchar(100)` | ✅ | — | Логин пользователя |
| `password` | `varchar(255)` | ✅ | — | Хэш пароля |
| `role` | `varchar(20)` | ✅ | — | Роль пользователя |

---

## 🔒 Ограничения таблицы

| Ограничение | Поле / поля | Описание |
|-------------|-------------|----------|
| `pk_users` | `id` | Первичный ключ |
| `uq_users_username` | `username` | Логин уникален |
| `chk_users_role` | `role` | Допустимые значения `USER` и `ADMIN` |

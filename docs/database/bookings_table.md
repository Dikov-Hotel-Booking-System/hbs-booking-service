# 📋 bookings

> Брони пользователей, даты проживания и состояние бронирования. Период `[start_date, end_date)` включает день заезда. День выезда может быть днём заезда для следующей брони.

## 🧾 Поля таблицы

| Поле | Тип | Обязательность поля | Значение по умолчанию | Описание |
|------|-----|------------------:|----------------------|----------|
| `id` | `bigint` | ✅ | `generated always as identity` | Идентификатор брони |
| `user_id` | `bigint` | ✅ | — | Владелец брони |
| `room_id` | `bigint` | ✅ | — | Идентификатор номера в Hotel Service |
| `request_id` | `uuid` | ✅ | — | Идентификатор запроса для идемпотентности |
| `start_date` | `date` | ✅ | — | Дата заезда |
| `end_date` | `date` | ✅ | — | Дата выезда |
| `status` | `varchar(20)` | ✅ | — | Статус брони |
| `created_at` | `timestamp` | ✅ | `now()` | Дата и время создания записи |

---

## 🔒 Ограничения таблицы

| Ограничение | Поле / поля | Описание |
|-------------|-------------|----------|
| `pk_bookings` | `id` | Первичный ключ |
| `fk_bookings_users` | `user_id` | Ссылка на `users.id` |
| `uq_bookings_user_request` | `user_id`, `request_id` | Один запрос пользователя соответствует одной брони |
| `chk_bookings_dates` | `start_date`, `end_date` | Дата выезда строго позже даты заезда |
| `chk_bookings_status` | `status` | Допустимые значения `PENDING`, `CONFIRMED` и `CANCELLED` |
